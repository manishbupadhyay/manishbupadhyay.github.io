# Manish Upadhyay — Portfolio

A modern, responsive professional portfolio for Manish Upadhyay, based on the supplied 2026 Scrum Master / PSM I resume.

## Files
- `index.html` — complete site
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation, reveal animations and current year

## Deploy to GitHub Pages
1. Replace the files in the existing `manishbupadhyay.github.io` repository with these files.
2. Commit and push to the `main` branch.
3. In GitHub: Settings → Pages, keep the source as the repository branch if it is not already configured.
4. Open `https://manishbupadhyay.github.io/`.

The public site intentionally omits personal details such as date of birth and nationality from the resume.
